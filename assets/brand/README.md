# Devin in a Box identity

The identity uses two related marks:

- `devin-in-a-box-primary.png` is the primary mark. Use it in the project
  README, documentation, announcements, and other layouts where its terminal
  and burst details have room to breathe.
- `devin-in-a-box-badge.png` is the compact mark. Use it for avatars, favicons,
  and other small or square placements. It deliberately uses one border weight,
  no spark ticks, and a heavy white cluster outline for legibility.

The `badge-16`, `badge-32`, `badge-128`, and `badge-512` PNGs are ready-sized
exports. `favicon.ico` contains 16, 32, and 48 pixel variants.
`social-preview.png` is a 1280×640 canvas ready for GitHub's social preview.

Both marks share the kraft-cardboard box, blue/teal module cluster, and navy
outline system. Do not add detail to the badge or use the primary mark below
approximately 96 pixels wide.
